# Instagram Login Page

A responsive Instagram-inspired login page created using HTML5 and CSS3.

## 📌 Project Overview

This project recreates an Instagram-inspired login interface using HTML and CSS. It was developed to practice front-end development, webpage structure, styling, and responsive design.

## 🛠️ Technologies Used

- HTML5
- CSS3

## ✨ Features

- Instagram-inspired login interface
- Username and password fields
- Login button
- Clean and simple user interface
- Responsive design
- CSS-based styling
